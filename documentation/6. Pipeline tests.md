# E6 Engine Tests

The matching tests live in `tests/` and install no Flask or SQLAlchemy dependency. The engine package contains its own pytest configuration and synthetic fixtures. Run these commands from the engine repository root.

```bash
python -m pip install -e '.[swiss,gtfs,acquisition,test]'
python -m pytest tests -q
```

For only the normalized in-memory API and predicate regressions, install `.[test]` and run `tests/test_api.py` and `tests/test_matching_regressions.py`.

Tests cover exact/name/distance/route predicates, ordered stages, source duplicate and OSM pair/trio propagation, independent runs, namespace-safe references, valid zero coordinates, co-located elements, missing route evidence, adapter parsing and the result writer. Source downloads are mocked; no national dataset or live network is needed.

`tests/test_progress.py` validates the versioned progress catalog and event lifecycle. These contract tests intentionally avoid exact durations and heartbeat counts. Algorithm tests remain independent: adding a public progress label must not require duplicating every matching assertion in an orchestration or browser test.

Database import tests belong to the review app. The former small-pipeline SQLite test mocked spatial and transaction operations; it has been replaced by bundle contract tests and actual PostGIS publication tests. See [CI and tests](https://github.com/openTdataCH/stop_sync_osm_atlas/blob/main/documentation/4.%20Test.md).
